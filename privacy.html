Privacy policy

This policy covers the privately operated INPoint Local Backup desktop utility and its informational website. The operator and maintainer is nikolskk-1. It does not cover other applications or services.

Data accessed and purpose

With the account holder's consent, the utility uses Google Drive read-only access to retrieve folder and file metadata, including names, identifiers, parent folders, file types, modification information and download availability, and to export the contents of selected Google Workspace files. It also reads ordinary files in the configured Google Drive for desktop folders.

This data is used to locate backup sources, create local copies, export documents, record a manifest and verify restoration. The drive.readonly permission technically covers all Drive files the account can access. The utility restricts backup processing to its configured folders. It does not modify Google Drive content or sharing settings.

Storage and protection

Archives, exported documents, file manifests and operational logs are stored on the operator's Windows computer. A manifest may include file paths, sizes, hashes and Google file identifiers or versions. Google authorization credentials are stored locally; the refresh token is protected with Windows DPAPI under the operator's Windows account. File permissions limit access to the operator, Windows SYSTEM and local administrators.

Backup archives are not independently password-encrypted ZIP files. Protection at rest depends on the computer's storage encryption and access controls. These controls do not prevent access by someone who controls the operator's signed-in account or computer.

Transfers and sharing

The utility communicates with Google's authorization and Drive API services over HTTPS to authenticate, request metadata and download exports. It does not upload backup contents, manifests or authorization tokens to GitHub, this website, an analytics service or an AI service. It does not sell Google user data or use it for advertising, profiling or training AI models.

INPoint Local Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, deletion and revocation

Local copies and logs remain until the operator deletes them under the applicable retention requirements. The current utility does not automatically delete older archives. Revoking authorization stops future API access but does not delete previously saved local backups.

The account holder can revoke the application's access through Google Account connections. To stop all future backups, also disable the scheduled Windows task. Local authorization files, archives and logs can be deleted by the operator when retention obligations permit. Source documents in Google Drive are not deleted by these actions.

This informational website

This static website does not request Google sign-in, accept file uploads or include advertising, analytics scripts or tracking cookies added by the maintainer. It is hosted by GitHub Pages. GitHub processes visitor information, including IP addresses for security, under the GitHub Privacy Statement. The backup utility does not send Google Drive data to this website.

Contact and updates

Questions about this policy can be raised in the project issue tracker. Issues are public: do not include personal documents, credentials, tokens or other confidential information. This page will be updated when the described data practices change.
