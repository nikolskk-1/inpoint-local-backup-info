Desktop backup utility

INPoint Local Backup

A privately operated Windows utility that helps the account holder save dated copies of selected Google Drive folders to their own computer.

What the application does

  • Copies ordinary files from configured Google Drive for desktop folders into local archives.
  • Uses the Google Drive API to identify and export Google Docs, Sheets and Slides as DOCX, XLSX and PPTX files.
  • Records a local file manifest and checks restored files against SHA-256 hashes.

Google account access

The account holder signs in to Google and grants the drive.readonly permission. This permission can read and download all Drive files accessible to that account. The utility's configured backup scope is limited to selected folders; that folder limit is enforced by the utility, not by the OAuth permission itself.

The utility does not create, edit, move or delete source files in Google Drive. It does not upload backup archives to this website, GitHub or another cloud destination.

Local operation

Backup files, manifests and logs remain on the operator's computer. The utility requires an available computer, access to the configured source folders and a valid Google authorization. Office exports do not preserve the complete Google Drive version history or sharing permissions.
